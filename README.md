# Steam Review Analyzer

Projeto de portfólio em Python com integração a API da Steam, persistência em PostgreSQL e análise de avaliações.

## Jogo inicial

- Cities: Skylines II (AppID 949230)

## Estado atual

A estrutura inicial está criada. A consulta à API ainda não foi implementada.

## Etapas planejadas

1. Consultar e exibir até cinco avaliações em português.
2. Buscar um lote de desenvolvimento de até 50 avaliações.
3. Armazenar avaliações em PostgreSQL, evitando duplicatas.
4. Classificar avaliações com IA, sem fornecer a recomendação da Steam ao classificador.
5. Consolidar resultados com pandas e, depois, disponibilizar funcionalidades com FastAPI.
